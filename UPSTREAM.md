KeepItClean is a GPL-3.0 fork and Swift port derived from [tw93/Mole](https://github.com/tw93/mole).

- Pinned port baseline: `e83f44f8ca56bb49f93c0479c82a984601b22d5d`

The public fork retains Mole's Git history and GPL license. The current runtime is intentionally reimplemented as a single Swift executable with a different product name and command surface. Original copyright remains with the Mole contributors. New KeepItClean changes are distributed under the same GPL-3.0 terms.

KeepItClean does not include CleanMyMac source code, assets, proprietary databases, or branding. Public MacPaw documentation was used only to benchmark product concepts such as reviewable cleanup and storage drill-down.
